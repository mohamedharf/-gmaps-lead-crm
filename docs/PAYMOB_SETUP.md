# Paymob Integration & Callback Setup Guide

Paymob requires a publicly reachable HTTPS URL to deliver server-to-server transaction callbacks (`POST /payment/callback/`) and browser redirects (`GET /payment/callback/`). `http://localhost:8000` is not reachable from Paymob's servers.

---

## Local Development with ngrok

1. Install and start `ngrok` pointing to your Django server:

   ```bash
   ngrok http 8000
   ```

2. Update `.env` with the HTTPS URL generated by ngrok and your Paymob credentials:

   ```env
   SITE_URL=https://<your-ngrok-subdomain>.ngrok-free.app
   ALLOWED_HOSTS=localhost,127.0.0.1,<your-ngrok-subdomain>.ngrok-free.app
   CSRF_TRUSTED_ORIGINS=https://<your-ngrok-subdomain>.ngrok-free.app
   ```

3. Configure your Paymob Dashboard:
   - Go to **Paymob Dashboard → Developers → Payment Integrations / Iframes**.
   - Set **Transaction Processed Callback** (Webhook) and **Transaction Response Callback** (Redirect) to:

     ```text
     https://<your-ngrok-subdomain>.ngrok-free.app/payment/callback/
     ```

   - Copy your **API Key**, **Integration ID**, **iFrame ID**, and **HMAC Secret** into `.env`.

---

## Security Notes

- Every `POST /payment/callback/` request is validated against `PAYMOB_HMAC_SECRET` using timing-safe SHA-512 HMAC verification (`verify_paymob_hmac`). Requests with missing or invalid signatures are rejected with HTTP `403`.
- Never commit `.env` or live merchant credentials to version control.
